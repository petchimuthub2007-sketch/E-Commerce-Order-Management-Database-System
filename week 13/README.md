# Week 13 – Database Security and Performance Optimization

## Project Overview
This project focuses on database security and query performance optimization using MySQL. It includes database user creation, access control, permissions, indexing, and query performance analysis.

## Objectives
- Create database users with different access levels.
- Manage permissions using GRANT and REVOKE.
- Prevent unauthorized database access.
- Improve query performance using indexes.
- Analyze query execution using EXPLAIN.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL
