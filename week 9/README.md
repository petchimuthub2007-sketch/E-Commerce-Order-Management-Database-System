# Sales and Customer Analytics System

## Overview

This project implements SQL queries for analysing sales and customer data in an E-Commerce Database. It is used to generate reports related to sales performance, customer purchases, best-selling products, and category-wise sales.

## Tables Used

- `customers`
- `products`
- `categories`
- `orders`
- `order_details`
- `payment`

## Reports Generated

- Sales Analysis Report
- Customer Purchase Analysis Report
- Best-Selling Product Report
- Category-Wise Sales Report

## SQL Concepts Used

- **SELECT** – Retrieves the required sales, customer, product, and category data.
- **JOIN** – Combines data from related tables.
- **SUM** – Calculates total sales, quantity, and revenue.
- **COUNT** – Counts orders and customer purchases.
- **AVG** – Calculates average order and customer spending.
- **GROUP BY** – Groups data by customers, products, and categories.
- **ORDER BY** – Sorts the results based on sales, quantity, or spending.
- **MAX / MIN** – Finds the highest and lowest values.
- **HAVING** – Filters grouped results.
- **LIMIT** – Displays a specific number of records.
