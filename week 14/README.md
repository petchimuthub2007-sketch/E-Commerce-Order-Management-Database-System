# Week 14 – Business Intelligence and AI Data Preparation

## Project Overview
This project focuses on analyzing e-commerce business data using MySQL. It includes sales analysis, customer behavior analysis, product ranking, customer segmentation, and AI-ready dataset preparation.

## Objectives
- Analyze sales and customer purchasing behavior.
- Generate business intelligence reports.
- Apply SQL window functions.
- Segment customers based on spending and purchase frequency.
- Prepare structured datasets for machine learning.
- Extract useful features from database records.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL
- Window Functions
- Common Table Expressions (CTEs)
